# Included Form Templates

CleverForms Core is intended to be useful immediately after installation. These starter structures can be recreated in the builder or imported as JSON as the template library matures.

## Contact form
Recommended fields: name, email, phone, subject, message, consent checkbox.

## Event registration
Recommended fields: attendee name, email, phone, organization, event/session choice, accessibility notes, consent.

## Intake form
Recommended pages: contact information, household/profile information, requested services, notes, consent.

## Application form
Recommended pages: applicant information, qualifications, availability, narrative questions, certification.

## Survey
Recommended fields: radio/select questions, multi-select questions, ratings represented by configured choices, open-response text areas.

Templates shipped in future releases must use only free Core field types and capabilities.
