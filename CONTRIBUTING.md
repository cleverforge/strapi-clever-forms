# Contributing

Thanks for helping improve Strapi CleverForms.

1. Open an issue for substantial behavior or API changes before implementation.
2. Keep Core provider-neutral. Do not add proprietary credentials, paid-service assumptions, or commercial-module source to this repository.
3. Add or update tests for behavior changes.
4. Run `npm run typecheck`, `npm test`, `npm run build`, and `npm run verify` before opening a pull request.
5. Explain what changed, why it changed, and how it was tested.

Security vulnerabilities must follow SECURITY.md and should not be reported publicly with exploit details.
